# 面试问题准备

## 为什么选择手写 Agent 循环？

题目核心是让 LLM 决定工具调用顺序。手写循环能够直接展示消息、工具 schema、工具结果和停止条件，依赖更少，也便于调试和测试。后续如果需要复杂状态图，可以迁移到 LangGraph。

## 如何证明工具顺序不是硬编码？

AgentRunner 只处理 LLM 返回的 tool_calls，不判断先搜索还是先读取。测试中让 Mock Provider 返回不同的工具顺序，Runner 都按照返回结果执行。

## 如何防止无限循环？

每次运行设置 max_steps。达到上限后返回 max_steps 状态，同时保留已有运行轨迹。工具调用异常不会直接导致进程崩溃，而是作为工具结果返回给 LLM。

## bash 工具有什么安全措施？

限制工作目录、允许执行程序、危险命令、Shell 链式操作、执行时间和输出长度。真实生产环境还应进一步使用容器、沙箱或独立执行服务。

## 为什么使用 Mock 模式？

Mock 模式让测试和演示不依赖外部 API Key、网络和模型服务，保证项目能够稳定复现。真实模式通过 OpenAI-compatible 配置切换。

## RSS 失败怎么办？

RSS 请求设置超时并捕获网络和解析错误。失败时回退到确定性的 Mock 新闻源，并在后续版本中记录数据源失败原因。

## 如何支持每天运行？

APScheduler 根据配置的小时、分钟和时区注册 Cron Job。调度器遍历用户并调用共享新闻生成服务，手动 API 和定时任务使用同一条业务逻辑。
